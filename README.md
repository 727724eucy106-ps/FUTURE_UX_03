# FUTURE_UX_03

## CRM / Client Management Dashboard UI

This project was created as part of the UI/UX Design Internship at Future Interns.

### Project Overview

A modern CRM dashboard UI designed for managing clients, appointments, analytics, and business workflows for a luxury beauty and wellness business.

### Features Included

* Dashboard Overview
* Client Management
* Lead Tracking
* Analytics & Reports
* Calendar & Tasks
* Notification Panel
* KPI Cards

### Tools Used

* Canva AI
* Canva
* Microsoft Word
* GitHub

### UI/UX Focus

* SaaS dashboard experience
* Workflow-based design
* Business analytics visualization
* Modern responsive dashboard UI
* User-friendly management flow
